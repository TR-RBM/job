# Service entry and access

## What it does

Runs the service when the program is invoked as `jobd` (or as `job daemon`), with `--system` and `--foreground`. Plans and binds the service socket in its runtime directory, takes an exclusive lock on `job.lock` in a runtime directory apart from the state directory and writes its state directory into it, refuses to start when another service holds it, only then removes a socket an earlier run left behind, and sets directory and socket modes. `discovery` chooses the cgroup root: an explicit root from `JOB_CGROUP_ROOT` or `[cgroup] root`, then the delegated cgroup the service runs in, then the earlier fixed path, and refuses a root that holds other processes. `access` admits a peer by its Unix user, or by membership of the configured socket group read with `SO_PEERCRED` and `SO_PEERGROUPS`, and carries the peer's user ID to records that name an actor. The daemon hands its resolved socket policy to each supervisor as `--socket-group GID:NAME`; a supervisor adopts that and never reads the configuration for it. The chosen rules are published in the startup line and in `job host --json` under `service`.

## How to test

`cargo test --test linux_integration` through job: `jobd_is_the_daemon_and_everyday_help_omits_internal_commands`, `a_group_shared_socket_gets_group_modes_and_needs_its_own_directory`, `an_unknown_socket_group_refuses_startup`, `another_user_is_admitted_only_through_the_socket_group_and_recorded_as_actor` and `a_private_socket_refuses_another_user_even_when_the_files_are_opened_up`; the last two need subordinate user IDs and print why they skip without them. The cgroup cases `the_cgroup_root_is_discovered_from_delegation_and_named_at_startup` and `a_cgroup_root_holding_other_processes_is_refused` run with `-- --ignored --test-threads=1` inside a writable delegated cgroup. The `review_*` cases cover two services on one runtime directory, the terminal socket's policy after a configuration edit, `--system`, and a refused peer in the audit journal. No unit tests.
